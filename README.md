# NSCLD Audio Measurement Workbench

NSCLD 是一个纯 Web 的音频与数字流测量工作台，用于 Codec、ADC、DAC、I2S/TDM 与时钟抖动排查。

直接双击 `index.html` 即可运行。不需要安装、构建、服务器或任何第三方库。首次打开会自动载入一段三通道测试信号，拖入文件即可开始分析。

## 运行要求

- 现代 Chromium / Edge，或支持 Canvas、Web Audio、LocalStorage 的现代浏览器。
- FLAC 解码使用浏览器内置 Web Audio `decodeAudioData`，无需外部解码库。
- 所有文件、信号与分析结果只在当前浏览器内处理，不上传、不联网。
- 支持直接 `file://` 打开；若浏览器策略限制本地文件访问，也可以用任意静态服务器托管该目录。

## 功能

### 信号导入

- WAV：PCM 8/16/24/32-bit、IEEE float 32/64-bit、WAVE_FORMAT_EXTENSIBLE。
- FLAC：浏览器 Web Audio 解码，保留原始采样率与通道。
- AP CSV：自动识别时间列、数值列、电压单位、多通道。
- 逻辑分析仪 CSV：BCLK / FS / DATA 列自动解码。
- 数字流二进制：TDM、I2S、左对齐、MSB/LSB First、slot 宽度、位偏移、有符号/无符号。
- PDM：抽取滤波。
- 内置三通道测试信号，便于无文件时体验完整流程。

### 时域

- 多通道分行或叠放显示，每通道独立自动 Y 范围。
- 鼠标滚轮 X 缩放、Shift + 滚轮 Y 缩放、中键框选缩放、双击中键复位。
- 左键设置游标 A，Ctrl + 左键设置游标 B，右键拖动选择分析区。
- 右键菜单可固定 Y 范围、设置游标、建立分析区。
- RMS、AC RMS、DC、峰值、峰峰值、波峰因数、功率与 dBFS 读数。
- 时域滤波：A-weight、ITU-R BS.468-4、低通、高通、带通、带阻；滤波后游标、RMS/峰值、抖动与播放源同步。
- 游标读数与测量卡标注滤波状态。

### 频谱

- Welch 平均 FFT，Hann / Blackman / Blackman-Harris / Hamming / FlatTop / 矩形窗。
- 自动或手动 FFT 大小，最高 262144 点。
- 单边幅度校准、对数/线性频率轴、对数频率刻度。
- A 计权、ITU-R BS.468-4 计权与通用滤波器响应。
- 多通道分行/叠放、光标吸附、谱峰与基波标记。
- 基波、THD、THD+N、SNR、SINAD、ENOB、噪底。
- 分析带宽设置与选区分析。

### 抖动

- 插值上升沿检测，避免把正负半周误计为两个周期。
- 周期误差趋势 / 相对误差直方图。
- 频率、RMS 周期抖动、峰峰值、周期间抖动、百分比。
- 对非周期或噪声信号自动拒绝抖动结论，避免输出虚假数值。

### 位域拆分

- 任意 WAV PCM 原始码字，或浮点信号的量化码字。
- 字段起始填实际 bit 号：31 = MSB，位宽向 bit0/LSB 方向展开。
- 支持 MSB First / LSB First、有符号/无符号、Scale、Offset、FullScale、单位。
- 每个字段独立归一化：`code / (2^width - 1)` 或有符号 `code / 2^(width-1)`。
- 修改位宽时，后续落入当前字段范围的起始位自动避让。
- 手动修改起始位允许重叠，并以琥珀色状态标识。
- 位域图解固定 bit31 在左、bit0 在右；重叠字段自动分泳道。
- 应用后每个字段成为独立分析通道，可随时恢复原始信号。

### 播放与导出

- Web Audio 播放，0.25x–4x 倍速，关闭/单次/连续循环。
- 播放原始信号或滤波后信号；有选区时播放选区。
- 导出当前通道 / 滤波信号为 16-bit WAV。
- 导出包含时域、频谱、抖动和位域配置的文本报告。
- 导出/导入工作台设置 JSON。

### 界面与持久化

- 暗色仪器主题：`#14161B` 背景 + `#56C4FF` 信号青。
- 亮色仪器主题，一键切换。
- 左侧导航轨 + 中央工作区 + 右侧读数卡列。
- 响应式布局，窄屏自动切换为纵向工作流。
- 主题、频谱布局、频率轴、循环、倍速、FFT、窗函数、加权、滤波、位域字段与图解开关通过 LocalStorage 持久化。

## 说明

- 浏览器对超长文件的 FFT 与滤波耗时取决于设备内存与 CPU。建议先选择分析区，再计算频谱。
- 浮动信号的位域解码会先量化到当前字宽；要获得真实原始位流，请导入 PCM WAV 或数字流二进制。
- A/BS.468-4 既可用于频谱与失真读数，也可作为时域滤波影响波形、游标、抖动与播放；同一曲线不会重复叠加。
